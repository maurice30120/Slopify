# Launch Slopify

Read [GUIDE.md](GUIDE.md) completely. Prepare `.scratch/slopify/spec.md` and `batch.json`, validate their complete task prompts and dependencies, then use `slopify tasks run/status/resume`. Run no more than five ready tasks per wave and keep Slopify's dedicated integration branch; never merge work into the user's current branch implicitly.
